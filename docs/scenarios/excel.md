# Excel 表格 + AI 提效

用四条虚构记录练习按状态统计金额。成品是一条可以在 Excel 中复核的条件求和公式。

![Excel 练习的单元格示意，B 列是状态，C 列是金额，已确认合计 200](/images/excel-check.webp)

| 单号 | 状态 | 金额 |
|---|---|---:|
| T01 | 已确认 | 120 |
| T02 | 待确认 | 75 |
| T03 | 已确认 | 80 |
| T04 | 待确认 | 45 |

## 可复制提示词

~~~text
Excel 的 B2:B5 是状态，C2:C5 是金额。
请写出统计「已确认」金额的公式，说明每个参数，
并给一个人工复核步骤。空值和金额为文本的情况单独说明。
~~~

## 人工复核

先筛选「已确认」，手算 120 + 80 = 200，再用 `=SUMIF(B2:B5,"已确认",C2:C5)` 对照结果。把 T02 的状态改为「已确认」可得到 275，用于验证公式是否跟着输入更新。

交付前确认金额列是数字、状态没有多余空格，检查求和范围覆盖最后一行。记录核对后的公式与示例数据，方便下次复用。

还可以用[数据核对三道关](./data-verify.md)复练独立复算和抽查。
