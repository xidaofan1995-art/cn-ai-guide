# 实战案例

从一项工作切入，带走一份可复用的材料或步骤。这里有日常办公练习，也会陆续补充制造出海的案例。

## 办公实战 {#office}

首批教程围绕文案、演示和工作总结展开。

### 写文案 {#writing}

把展会沟通记录整理为英文跟进邮件，目标是拿到客户图纸或关键规格。[打开写文案教程](./writing.md)

### 做 PPT {#slides}

把业务记录转成可核对的五页汇报大纲，再制作可编辑 PPTX。[打开做 PPT 教程](./slides.md)

### 写周报 {#weekly-report}

把零散记录整理成一页周报，检查数字、状态和负责人。[打开写周报教程](./weekly-report.md)

### Excel 表格 {#excel}

用一份小表练习条件求和和人工复核。[打开表格练习](./excel.md)

### 数据核对

从分步展示、独立复算到抽查锚点，练习如何复核 AI 的数字结果。[数据核对三道关](./data-verify.md)

## 制造出海 {#export}

- [写展会后的英文跟进邮件](./writing.md) · 用练习材料问清图纸、规格和试制数量。
- [做一份展会客户跟进汇报](./slides.md) · 用虚构业务记录整理进展、风险和下一步行动。
