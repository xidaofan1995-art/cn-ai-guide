# 场景教程

按职业和行业分类的AI实战教程，持续更新中。

## 办公实战 {#office}

首批教程围绕文案、演示和工作总结展开。

### 写文案 {#writing}

把展会沟通记录整理为英文跟进邮件，目标是拿到客户图纸或关键规格。[打开写文案教程](./writing.md)

### 做 PPT {#slides}

把业务记录转成可核对的五页汇报大纲，再制作可编辑 PPTX。[打开做 PPT 教程](./slides.md)

### 写周报 {#weekly-report}

把零散记录整理成一页周报，检查数字、状态和负责人。[打开写周报教程](./weekly-report.md)
