# 数据核对：AI 算的数敢不敢用

![数据核对配图：花园里同时使用计算器和算盘的小园丁](/images/scenarios-data-verify.webp)

> 你将带走：一套"三道关"核对流程 + 一个可复制的核对提示词。

先回答标题的问题：**AI 算的数，过完三道关才敢用。** 不是因为它经常错，而是它错起来毫无征兆——语气和算对时一模一样。

## 为什么 AI 会算错

模型生成的算式和中间结果可能出错，即使产品能调用计算工具，输入、公式和口径也要核对。

## 三道关流程

### 第一关：让它自己展示过程

```text
请计算下面这笔报价，要求：
1. 分步列出每一步的算式和中间结果
2. 每步说明数据来源（对应我给的哪条信息）
3. 最后给总和
4. 不要心算，一步一步写出来。

原始数据：
【逐条列出：单价、数量、折扣、税率、运费……】
```

分步展示让你能定位哪一个输入或算式出了错。

### 第二关：换个方法再算一遍

- 让它**换一种算法**复核：「请用另一种方法验算上面结果」（比如乘法换除法、求和换分组求和）
- 或用**反向核对**：「如果总价是 X，反推单价应该是多少？和我给的是否一致？」

用计算器或表格独立复算。两个结果一致时仍要核对输入口径；有差异就逐段查。

### 第三关：抽查锚点

从结果里挑 1-2 个数字，用计算器**手算抽查**。抽查能发现部分错误。关键报价、税率和对外结算应逐项核对。

## 什么任务必须走全三道关

| 任务 | 最低要求 |
|------|---------|
| 发给客户的报价 / 结算 | 三道关全走 |
| 内部预估 / 初稿数字 | 第一关 + 抽查 |
| 数据清洗 / 排序 / 格式转换 | 抽查 + 总数核对（行数对不对） |
| 图表数据 | 逐个和原始表核对刻度与数值 |

## 踩坑点

- **"它上次算对了"**：同一类题换个数字就可能错，每次都按流程走
- **只核对了总额**：总额对不代表每一项对（可能正负误差相抵），抽查要挑单项
- **在对话里改数字重新算**：上下文越长越容易带错，新数字开新对话
