# 工具实测

按任务测试国内外 AI 工具。先固定输入和验收标准，再看每款工具能完成哪一步，哪些地方需要人工检查。

## 已发布

**[周报同题测试](../compare/weekly-report.md)** · 用同一份展会跟进记录对照两款本地模型。文章附测试条件、原始回答和人工核对记录，归档在「AI 基础 → 大模型」。

## 实测计划

| 任务 | 主要想验证什么 | 状态 |
|---|---|---|
| [海关数据收集与整理](./trade-data.md) | 能否找对来源、保留统计口径、输出可复核的表格 | 待实测，已有测试口径 |
| [展会洞察](./exhibition.md) | 能否从公开材料整理展商与品类，并区分事实和推断 | 待实测，已有测试口径 |

后续也会关注跨境竞品调研、客户线索去重、长文档阅读。等拿到可复现的结果，再把原始产出和实际用时补进来。
