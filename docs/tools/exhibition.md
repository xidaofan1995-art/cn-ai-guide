# 展会洞察

**状态：待实测。** 这一页列出测试输入和验收方法。

## 要完成的任务

选定一届展会和一个品类，例如广交会的五金工具，先整理参展商和展品，再核对哪些信息支持采购观察。

1. 在[广交会官网](https://www.cantonfair.org.cn/)查展商、展品和展位，锁定届次、期数和品类。
2. 给不同工具相同的资料，要求输出展商名称、展位、产品类别和对应来源。对重复名称保留合并依据。
3. 将「官方名录事实」「可公开的现场记录」「分析推断」分开记录。用样例检查同名展商、届次和展位是否混淆。

建议表头｜展会与届次、参展商、展位、展品、证据类型、来源链接、观察日期、下一步核实事项。

## 结果怎么验收

随手抽一条记录可以点回来源。任何关于采购需求变化的判断都能说明依据。只有展商名录时，先发布展商和供给侧观察，采购需求可以用现场访谈或其他公开资料补证。
