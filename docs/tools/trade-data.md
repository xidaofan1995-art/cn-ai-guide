# 海关数据收集与整理

**状态：待实测。** 这一页公开测试方法和可用的官方入口。

## 要完成的任务

用同一组公开查询条件，整理某一类紧固件的进口数据，回答某个市场近几年的进口变化和主要来源。输出一份可溯源的表格，再据此写出简短观察。

1. 先用 [UN Comtrade 官方贸易统计](https://comtrade.un.org/en/trade-statistics)确认可用范围。记录 HS 版本及代码、报告国、伙伴国、贸易流向和年份。
2. 让不同工具用同样的条件输出表格，保留查询链接、单位和原始字段。把缺报和零值分开。
3. 抽查原表和汇总，确认分项与合计可核对。把源数据、清洗后的数据和分析结论分开保存。

建议表头｜报告国、伙伴国、贸易流向、年份、HS 版本、HS 代码、金额及币种、数量及单位、来源链接、提取日期。

## 结果怎么验收

另一位读者可以用同一套口径找回记录，能解释缺报、口径变化和合计差异，再据此判断趋势。行业或客户级线索若来自其他数据库，会单独标明来源和数据层级。
