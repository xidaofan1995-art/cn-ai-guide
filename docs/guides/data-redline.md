# 数据红线：哪些东西绝不能贴给 AI

![数据红线配图：红丝带围住花园里最重要的文件箱](/images/guides-data-redline.webp)

> 你将带走：一张可打印的红线清单 + 员工一句话记忆版。

团队开始使用 AI 前，可以先定下这些数据边界。**红线不是限制效率，是让团队放开手脚的前提**——规则清楚，大家才敢用。

## 红线清单（绝对禁止贴给公共 AI）

以下内容无论多方便，都不进公共对话：

| 类别 | 具体例子 | 为什么 |
|------|---------|--------|
| 客户身份信息 | 客户名单、联系方式、身份证号、地址 | 涉及个人信息，按授权、用途与组织规定处理 |
| 商业机密 | 成本底价、报价折扣底线、未公开的合同条款 | 贴出去等于交底 |
| 财务凭证 | 完整银行账号、工资表、税务底稿 | 涉密且不可撤回 |
| 技术与配方 | 工艺参数、配方、图纸、源代码核心部分 | 企业命根子 |
| 未公开经营信息 | 融资计划、并购意向、裁员计划 | 知晓面越少越好 |

**关键认知：贴进公共 AI 的内容=交给了第三方服务器，且难以撤回。** 拿不准的，一律按红线处理。

## 黄线（脱敏后可用）

大段日常数据想用 AI 加工，先脱敏：

```text
脱敏三招：
1. 替换：真实姓名 → 客户A/B/C；真实金额 → 按比例缩放
2. 删减：只保留任务必需的字段（算趋势不需要具体客户名）
3. 打散：把一段完整信息拆成无关联的片段分别处理

例：如果只需练习汇总，可以构造「客户A，数量 300，示例单价 60」。
    若保留原数量、价格或日期仍能关联到某人或企业，继续删减或改用虚构记录。
```

## 绿线（放心用）

优先使用获准公开的资料、虚构样例和行业通识问题。自己的草稿如果包含内部信息，也应按公司规则处理。仅换成代号仍可能被重新识别，参考 [《个人信息保护法》第七十三条](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)。

## 员工一句话记忆版

> **"人名手机号不上屏，底价配方不外传，拿不准就先脱敏。"**

建议把这句话和红线清单一起打印贴在工位。完整的一页纸制度模板见[团队规范草拟模板 P25](/prompts/#p25)。

## 人工复核

- 每季度回访一次：各家 AI 产品的隐私条款和训练授权设置会更新，复核一遍
- 涉及合规的行业（医疗、金融、教育）请让法务过目本文清单后再落地——本文是操作建议，不构成法律意见

## 踩坑点

- **只口头说红线，不落纸面**：出事时说不清。一页纸 + 签收记录
- **默认付费版就绝对安全**：付费改变服务条款，不改变"数据出了你的域"的事实；涉密需求请评估企业版/私有化方案
- **红线一刀切禁止用 AI**：全面禁用只会把使用赶进地下，反而失控
