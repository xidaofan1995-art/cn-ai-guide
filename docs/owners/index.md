# 老板专栏

从小团队重复做的工作里选一件，用虚构或经过授权的练习材料试跑，记录处理时间和人工修订。

## 小老板降本三板斧 {#three-plays}

| 场景 | 先试什么 | 验收口径 |
|---|---|---|
| 客服话术 | 把公开的常见问题整理成回复草稿 | 政策、交期和费用都有依据，待定项交给负责人 |
| 营销文案 | 把展会沟通变成一封[客户跟进邮件](../scenarios/writing.md) | 收件人知道下一步需要提供什么 |
| 周报汇总 | 把零散记录整理成[项目周报](../scenarios/weekly-report.md) | 成果、卡点和负责人均有出处 |

试跑时记录原做法耗时、AI 草拟时间、人工复核时间和两种做法的遗漏项，再判断该工作是否值得复用。

## 给团队定 AI 使用规范 {#team-rules}

- **输入范围。** 使用公开信息、经审批的脱敏材料或虚构数据。员工、客户和交易信息按公司的授权规则处理。
- **人工审核。** 涉及价格、交期、合同条款和对外政策的草稿，由业务负责人对照正式文件确认。
- **对外发布。** 保存引用材料和修改记录，由有权限的人确认最终版本。
- **出现错误。** 记录原材料、指令和错误句，修订后使用另一份练习材料复测。
