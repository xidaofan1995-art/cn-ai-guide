# 一句话选模型速查卡

![速查卡配图：花园里的分岔小路指示牌](/images/models-quick-pick.webp)

> 你将带走：按职业和任务类型的双维度选型表。打印出来贴在显示器边上。

**先说总原则：不存在"最好的模型"，只存在"最配你任务的模型"。** 下表是便于上手的试用建议。模型与入口会变，可以用自己的样例复测。

## 按职业看

| 你的角色 | 主力建议 | 理由一句话 |
|----------|---------|-----------|
| 行政 / 助理 | DeepSeek（写作算账）+ 豆包（看图杂活） | 任务最杂，需要两件趁手工具 |
| 销售 / 商务 | Kimi（读客户资料）+ DeepSeek（写跟进话术） | 大量读资料 + 少量写 |
| 财务 / 数据岗 | DeepSeek（公式推理）+ Excel 本体 | 数字工作，验证习惯最重要 |
| 设计 / 内容岗 | 千问（图片理解）+ 各家文生图按需 | 多模态是主战场 |
| 中小老板 | 豆包工作（账号支持时试模型）+ DeepSeek（定方案） | 先聚合着试，再固定主力 |
| 外贸 / 出海 | Kimi（长邮件往来）+ DeepSeek（双语写作） | 长文本和双语是日常 |

## 按任务类型看（更可靠）

职业只是粗分，**按任务选才精准**：

| 任务 | 首选 | 备选 |
|------|------|------|
| 写方案 / 做推理 / 算账 | DeepSeek | GLM |
| 读长文档（合同、标书、报告） | Kimi | 千问 |
| 表格处理 / 公式生成 | DeepSeek | 千问 |
| 图片理解 / 拍照识别 | 千问 | 豆包 |
| 会议纪要 / 转写整理 | 豆包 | Kimi |
| 日常快问快答 | 手边任意一家 | —— |
| 数据敏感任务 | 经组织批准的本地或企业环境（见[数据红线](/guides/data-redline.md)） | —— |

## 三条使用铁律（比选型更重要）

1. **主力固定一个，熟悉它的脾气**——换模型的学习成本常大于收益差异
2. **每月花 10 分钟重测一次**——用你固定的 3 道真题（见[DeepSeek 实战自测](/models/deepseek-self-test.md)的自测清单），格局变了就调整
3. **任何输出过验证三步法**——选型解决"好不好用"，验证解决"敢不敢用"
