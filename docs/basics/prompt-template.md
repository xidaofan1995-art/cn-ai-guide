# 第一条好提问：四段式提示词模板

![四段式提示词配图：四块积木搭出的提问框架](/images/basics-prompt-template.webp)

> 你将带走：一个万能提示词框架 + 5 个改好空的任务模板，复制就能用。

多数人第一次用 AI 的问法是：「帮我写个周报」。这种问法得到的回答往往"正确但没用"——因为它不知道你是谁、写给谁看、有什么素材。

问题不在模型，在于你只给了它 20% 的信息。

## 四段式框架

一条好提问由四段组成，顺序固定：

| 段 | 名称 | 作用 | 常见遗漏 |
|---|------|------|---------|
| 一 | **角色** | 告诉 AI 用什么身份回答 | 从不写，得到百科式泛答 |
| 二 | **任务** | 说清要产出什么、给谁看 | 只说"帮我写"，不说给谁看 |
| 三 | **素材** | 把原始材料贴进去 | 空手让 AI 编，输出全靠想象 |
| 四 | **要求** | 格式、字数、语气、禁止事项 | 忘了说"不要什么" |

一句话记忆：**你是谁 / 做什么 / 凭什么做 / 做成什么样**。

## 通用模板（复制即用）

```text
你是一位【角色，如：制造业外贸公司的业务助理】。
请帮我【任务，如：把下面的会议记录改写成给客户看的跟进邮件】，
读者是【谁，如：上周展会认识的一位德国买家】。

【把你的原始材料完整贴在这里】

要求：
1. 语言【中文 / 英文】，字数【X 字以内】
2. 语气【正式 / 亲切 / 简洁】
3. 不要【编造没有的信息 / 使用夸张词汇】
4. 如果材料里有不清楚的地方，先列出来问我，不要自己猜。
```

最后一条「先问我再动手」特别值得养成习惯——它会挡住大部分一本正经的编造。

## 5 个任务模板

以下模板的【】处是填空位，示例数据均为虚构。

### 1. 写周报

```text
你是一位帮我整理工作的助理。
请根据下面我随手记的工作流水，写一份周报，读者是我的直属上级。

流水记录：
【逐条贴上这周做了什么，多零散都行，如：周一打电话回了 8 个客户；周三报价单改到第 3 版；周五仓库盘点】

要求：
1. 按本周完成 / 进行中 / 下周计划三栏组织
2. 突出结果和数字，不夸大
3. 300 字以内，语气平实
4. 流水里没有的进展不要编。
```

### 2. 改邮件语气

```text
你是一位沟通教练。
请把下面这封邮件改得更【委婉 / 更直接 / 更正式】，
对方是【合作了三年的老客户 / 第一次联系的潜在客户】。

原邮件：
【贴上你写好的草稿】

要求：
1. 保留全部事实信息，只改语气和结构
2. 改完用两句话告诉我你改了哪里、为什么。
```

### 3. Excel 公式

```text
你是一位 Excel 老师。
我的表格：A 列是单号，B 列是状态（值为「已确认」或「待确认」），C 列是金额，
数据在第 2 到第 51 行。

请给我一个公式：统计「已确认」的金额总和。
要求：
1. 给出公式和每个参数的解释
2. 说明如果金额列里有空格或文本会怎样
3. 给我一个能验证结果对不对的手算方法。
```

### 4. 会议纪要

```text
你是一位会议记录整理员。
下面是一段会议录音转写的原始文字（可能很乱、有重复）。

原始转写：
【贴上转写文字】

要求：
1. 整理成：议题 / 结论 / 行动项（责任人 + 截止时间）三部分
2. 只用会上真实说过的话，转写里没有的不要补
3. 不确定归属的发言标注「待确认」。
```

### 5. 长文档找要点

```text
你是一位细心的合同助理。
请阅读我上传的这份文件，只回答以下问题：

1. 付款条件和账期是什么？
2. 有哪些条款对我方明显不利？
3. 有没有提到自动续约或违约金？

要求：每个答案后面注明出自原文哪一段（引用原句），找不到就写"文中未见"。
```

## 人工复核

AI 输出之后，固定做三个动作：

1. **对事实**：输出里出现的数字、日期、人名，逐个回到你的原始材料里核对一遍
2. **对格式**：周报是不是三栏、邮件称呼对不对——格式错了直接说「把第 2 条改成……」让它改，不要重开对话
3. **读一遍语气**：发给客户前，用「如果我是收件人」的视角通读，别让 AI 的客气过头变成油腻

## 踩坑点

- **一次塞太多任务**：「帮我写周报、改邮件、再做表格」三件事挤一条提问，每件都做不好。一个对话只干一件事，干完再开新的
- **素材舍不得贴**：只给一句"大概情况"，AI 只能编。素材越具体，输出越可用
- **不提"不要什么"**：不说禁止事项，AI 会替你加戏（编数据、加排比句、喊口号）
