# AI 回答错了怎么办：验证三步法

![验证三步法配图：放大镜下的文档检查](/images/basics-verify-answers.webp)

> 你将带走：一套 10 秒判断"能不能信"的分级法 + 3 个固定的核对动作。

先说结论：**AI 不是错的，是"不确定的"**。它按概率生成文字，所以最危险的不是明显胡说，而是用完美语气说出的错误事实。你要养成的不是怀疑一切，而是**分级信任**。

## 第 0 步：先分清两类问题

| 类型 | 例子 | 信任策略 |
|------|------|---------|
| **加工类** | 把我这段话改通顺 / 总结这份记录 / 按模板写信 | 输入对，输出基本对——重点核对**有没有漏** |
| **事实类** | 法定节假日是哪天 / 这个税率是多少 / 这家公司成立几年 | 输出**必须核对**，哪怕语气再肯定 |

90% 的翻车都发生在事实类问题被直接转发出去的那一刻。

## 验证三步法

### 第一步：找出处

在提问时就加一句：

```text
回答时请注明：哪些内容你有把握、哪些是可能过时的。
不确定的部分直接说不确定。
```

有这句，AI 会主动交底；交底越含糊的部分，越要核对。

### 第二步：交叉核对

事实类回答，换一个**独立来源**验证：

- 政策、税率、假期 → 政府官网原文（不是自媒体转述）
- 产品参数、价格 → 官方页面或你手头的原始文件
- "某公司/某人说" → 直接搜原文出处

注意：**用另一个 AI 验证不算交叉核对**——两个模型可能错得一样。

### 第三步：小样试错

要在重要场合使用前，先拿一个**你知道正确答案的问题**测试。它答对了，说明当前状态可用；答错了，说明这个话题你要全程人工把关。

## 最容易错的五类内容

1. **数字计算**（尤其多步计算）——见[数据核对：AI 算的数敢不敢用](/scenarios/data-verify.md)的固定复核动作
2. **日期和时效信息**——政策、价格、版本号，一律标注"截至 YYYY-MM"再引用
3. **引用名言**——张冠李戴重灾区，发出去前查原句
4. **法律、税务、医疗的具体结论**——AI 可以帮你理解概念，**决定前必须问专业人士**
5. **冷门实体的细节**——越小众的公司/人物/产品，越容易编造

## 发现错了怎么办

直接指出来，让它改：

```text
你上面第 2 点说错了：实际是【正确信息】，依据是【来源】。
请只修正这一处，重新输出，其他部分不动。
```

这个修正过程本身值得保留——同一类错误第二次出现时你会更快识别。

## 踩坑点

- **"语气自信 = 内容可靠"**：模型不知道自己错，语气永远像专家
- **复制粘贴去验证太麻烦，干脆不验**：把三步法压成习惯后，每条事实类信息只多花 30 秒
- **用"再问一次 AI"替代查原文**：这是把赌注加倍，不是验证
