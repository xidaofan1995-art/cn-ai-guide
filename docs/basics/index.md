# AI 基础

从你手上的任务出发，弄清 AI 在哪一步起作用，然后挑一条能跟着练的路线。

| 你想解决的问题 | 从这里开始 |
|---|---|
| 第一次接触，想试着做一件工作 | [零基础 7 天练习](../start/index.md)，从一封跟进邮件做到一份可编辑的汇报 |
| 面对很多模型，想知道怎么选 | [国产大模型能力地图与三道职场实测](../models/overview.md) |
| 想把一项重复工作交给程序跑 | [Token 和大模型 API](./concepts.md#token)，认识用量、输入和输出 |
| 想用智能体读取文件、整理资料 | [Agent、CLI 与 MCP](./concepts.md#agent)，弄清由谁执行、从哪操作、怎么接工具 |

## 先拿一份材料做练习

- [四段式提示词](./prompt-template.md) · 把角色、任务、材料和要求写清楚。
- [注册与账号安全](./account-safety.md) · 选一个主力入口，检查账号和隐私设置。
- [验证三步法](./verify-answers.md) · 先找出处，再交叉核对和小样试错。
- [个人数据安全三道门](../guides/data-security.md)和[团队数据红线](../guides/data-redline.md) · 确认哪些信息可以交给 AI。
- [提示词库](../prompts/index.md) · 收录 P01–P30，可按任务复制和复跑。

试着用同一份工作记录写周报。第一次读[周报实战](../scenarios/weekly-report.md)，看原始材料该怎样整理。第二次看[两款模型的原始回答](../compare/weekly-report.md)，对照数字、日期和责任人。等到你开始反复做同一件事，再看 API 和 Agent 能帮你省掉哪些步骤。

更多国内外工具的试法和记录集中在[工具实测](../tools/index.md)。
