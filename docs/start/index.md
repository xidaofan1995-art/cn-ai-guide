# 零基础 7 天上手路径

按顺序做一遍，每天留下一份可检查的产出。7 天是学习安排示例，可以按工作节奏调整。

| 天数 | 阅读或练习 | 留下什么 |
|---|---|---|
| 第 1 天 | [DeepSeek 入门](../models/deepseek.md) | 一个可以打开的对话入口 |
| 第 2 天 | [通义千问入门](../models/qwen.md) | 一条包含任务、素材、格式和限制的指令 |
| 第 3 天 | [客户跟进邮件](../scenarios/writing.md) | 一封经过人工审阅的邮件 |
| 第 4 天 | [一页周报](../scenarios/weekly-report.md) | 一份保留原始记录编号的周报 |
| 第 5 天 | [Excel 表格练习](../scenarios/excel.md) | 一条用手算复查过的求和公式 |
| 第 6 天 | [五页汇报 PPT](../scenarios/slides.md) | 可以编辑的五页演示文件 |
| 第 7 天 | [周报同题对比](../compare/weekly-report.md) | 一份可重复使用的核对清单 |

## 保存自己的提示词模板

把重复任务分成「每次都相同的指令」「每次变化的输入」「交付前检查」三部分。选一份新的虚构材料复跑，再用核对清单记录哪些步骤还需要调整。
