# AI客户背调全景：从公司名到采购决策人的信息链路

**D09 · AI×外贸出海 · 公开初稿 / 2026-11-27**

![证据链比AI摘要更重要](/images/topics-d09.svg)

## 30秒概览
先查清楚是谁，再判断做什么、是否匹配、如何联系。背调不等于挖掘个人隐私，公开业务证据也不能证明实际采购意向。

## 5分钟理解与决策
| 步骤 | 输入/输出 | 工具方向与验收 |
| --- | --- | --- |
| 主体核验 | 公司名→名称、域名、地区 | 官网、官方注册库；处理同名 |
| 业务核验 | 产品与市场→应用和角色 | 产品页、年报、公开新闻；交叉验证 |
| 贸易线索 | 合法可得明细→可能采购关系 | 免费统计/商业明细；口径与主体核验 |
| 采购角色 | 公开岗位与联系方式→待联系路径 | 官网、公开职业资料；不得猜造邮箱 |
| 风险检查 | 证据冲突与缺失→待核问题 | 相关官方登记或授权服务 |

免费源可先解决主体、官网、公开产品和宏观市场；付费数据适合有持续、合法、明确需求且试用验收的场景。费用与覆盖动态，不假定每国都有企业级明细。

## 深度探索：单家公司执行清单
记录：原始名称/别名、网址、注册地、业务证据、可能需求、采购角色、公开联系入口、来源日期、冲突、待核事项和下一步。逐个打开关键来源，不能把AI生成简介当事实；同一新闻转载多次不算独立证据。不要收集与商业目的无关的个人资料，也不公开客户名单。若找不到可靠采购人，应保留“未核实”，通过官方业务入口咨询。示例为通用流程，没有具体企业调查结果。
