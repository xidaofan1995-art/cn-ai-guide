# 智能摄像头全景：从看家到主动感知

## 30秒概览
摄像头不是像素越高越好。要看是否看得清、识别正确、稳定送达，并在用户可控的隐私和费用范围内工作。

## 5分钟理解与决策
| 场景 | 关注点 | 验收 |
| --- | --- | --- |
| 室内看家 | 广角、隐私遮蔽、事件识别 | 多人、逆光、遮挡 |
| 室外 | 防护、夜视、网络及供电 | 雨夜、距离、树影误报 |
| 门铃 | 门口事件、双向语音 | 唤醒、响应、断网 |
| 婴宠看护 | 音视频与提醒 | 漏报、误报、数据控制；不能替代照护 |

镜头和传感器决定采集基础，ISP和编码影响图像质量与码率，SoC及算法影响事件识别，App、存储和推送决定最终体验。端侧可减少上传与延迟，但受算力、功耗、散热制约；云端便于更新和远程服务，却需要网络、隐私条款和持续成本。Matter连接互操作不代表厂商专属AI、云录像、回看和订阅功能都等价。

## 深度探索：如何定义一项可测试的功能
以“门口有人时提醒”为构造案例，固定光照、距离、人物、动物、阴影和网络条件，分别记录检出率、误报频率、告警时延、录像缺失、断网恢复和功耗。明确默认录制区域、授权用户、保存与删除、固件更新。实际摄像头使用须尊重他人隐私并遵守当地规则，不能依赖AI判定安全事件。尚无真实评论统计、竞品实测或市场数据，不做优劣排行。
