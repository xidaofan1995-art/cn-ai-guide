# AI外贸的合规红线：客户数据、邮件触达与跨境隐私

## 30秒概览
公开邮箱不等于可以任意群发。先判断市场、联系人类型、数据处理依据与联系规则。AI生成邮件不改变发送者的责任。法规动态，本篇不构成法律意见。

## 5分钟理解与决策
| 地区 | 官方核查入口 | 注意 |
| --- | --- | --- |
| 美国 | [FTC CAN-SPAM指南](https://www.ftc.gov/business-guidance/resources/can-spam-act-compliance-guide-business) | 商业邮件需真实标头与主题、识别发送者、有效退出等 |
| 欧盟 | [GDPR原文](https://eur-lex.europa.eu/eli/reg/2016/679/oj) | 合法依据、目的限制、最小化、透明、反对权；电子营销另查成员国规则 |
| 英国 | [ICO B2B营销指南](https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/business-to-business-marketing/) | PECR区分企业订户与个人订户；个人数据仍受数据保护法约束 |

FTC与ICO指南于2026-11-27查阅；GDPR为2016年法规原文入口，实施及成员国规定需由专业人员确认。不要将一个地区的B2B规则套用全球。

## 深度探索：上线前自查
- 来源与采集目的是否合法、必要？联系方式是否真实核验？
- 是否记录适用市场、联系人类型、处理依据、告知和退订方式？
- 是否限制AI访问权限，确认服务商处理条款、保留和跨境条件？
- 是否审核发件人、主题、宣传内容及退订状态，避免虚假承诺？
- 是否定义删除、纠错、反对处理与抑制名单规则？

不确定时停止自动触达，查官方规定并咨询专业人员；不要规避平台限制或用推测邮箱群发。作者业务合规审计未开展。本页为风险识别框架而非合规认证。
