# 从零搭建海外潜客开发工作流：市场、名单、核验、触达

**D02 · AI×外贸出海 · 初稿 / 方案研究 · 2026-11-27**

> 本页为公开初稿，可持续修订；作者未补充的个人观点留空，构造案例、AI建议与实际测试分开。动态信息在后续更新前复核。

![不以名单数量取胜，而以可核验的采购匹配为目标](/images/topics-d02.svg)

## 30秒概览

1. 名单不是客户，采购匹配度和证据才是线索价值。
2. 先定义理想客户，再收集、核验、去重、评分。
3. AI 可加速整理及起草，但不应编造联系人或未经许可批量触达。

## 5分钟理解与决策

ICP（理想客户画像）应包含市场、下游应用、采购角色、规格范围、预计采购方式和排除条件。以精密零部件供应商为构造示例，不是作者的真实客户：先看产品材料、公差和可供批量，再定位实际需要对应部件的整机厂、配套厂或经销商，而非向所有电子企业群发。

| 步骤 | 输入 | 输出 | 验收 |
| --- | --- | --- | --- |
| 市场选择 | 产品范围、目标地区 | 国别及品类优先级 | 商品代码、报告国、年份可追溯 |
| 名单收集 | ICP 与公开来源 | 候选公司列表 | URL、来源日期和采集条件 |
| 主体核验 | 官网、注册/名录 | 去重后的公司实体 | 名称、域名、地区一致 |
| 采购匹配 | 公开产品、应用、采购线索 | 匹配理由和待核问题 | 证据支持，不将推测当采购事实 |
| 联系与沟通 | 已核公开业务联系方式 | 个性化草稿 | 地区合规、人工确认 |
| CRM 回写 | 回复、退订、失败 | 状态与下一步 | 可追踪且尊重拒绝 |

【已核事实】[UN Comtrade](https://comtrade.un.org/en/) 提供按报告国、伙伴、商品等维度的贸易统计（2026-11-27 查阅）；统计能帮助判断市场，但通常不能直接作为企业级买家名单。企业级明细的合法性、覆盖范围、原文与时间要单独核查。[海关数据选型专题](../tools/trade-data.md)已介绍不同口径，本文聚焦下游获客流程。

### 从一个公司名到可跟进的线索

| 字段 | 记录方法 |
| --- | --- |
| 公司名称 / 官网 | 原文记录、别名与域名 |
| 目标应用与采购角色 | 产品页、公开资料；推测单列 |
| 规格匹配 | 已知能力与可能需求对应 |
| 联系信息 | 仅记录合法、已核验的业务联系方式 |
| 证据 | URL、日期、摘录与未确认项 |
| 状态 | 待核、已核、待联系、已拒绝、暂停等 |

评分可以先采用简单分档：高匹配且有两类独立证据 → 优先核验；应用相近但无采购证据 → 待核；明显不符合范围 → 排除。这是建议筛选规则，不是成交概率模型。

## 深度探索：AI在哪一步创造价值？

AI 可以把网页信息提取成表格、提示同名公司冲突、标记缺项、归类下游应用、生成跟进草稿。它不能把遮挡记录补成真实值，也不能把推测邮箱写成已确认。不同来源的同一条转载不算独立证据。

触达前应核查当地商业通信及数据处理规则，尊重拒绝与退订；不要把展会名片默认变成可群发名单。具体合规要求需查目标市场官方规则或专业意见，本篇不提供跨国法律结论。

建议先用少量线索完成完整流程，记录核验率、匹配率、回复质量、人工时间、退订及失败原因，再决定是否扩大规模。不要以收集数量作为唯一 KPI。
