## 30秒概览
订阅按期限或额度、API按实际用量、本地模型按设备和维护计成本。不能只拿单价比较：同样一项工作，成功率和人工修订会影响总成本。

## 5分钟理解与决策
| 方式 | 常见成本 | 适用任务 |
| --- | --- | --- |
| 订阅 | 月费、额外额度、人工操作 | 高频日常对话 |
| API | 输入、输出、推理或工具费用、重试 | 批量调用及产品集成 |
| 本地 | 折旧、电费、维护、质量差距 | 离线、受控数据或高频验证 |

## 深度探索：成本分母用合格任务
设每月尝试N次，合格率r，单次输入和输出价格分别按百万token计。基础API成本=尝试次数×单次token成本；若额外重试，计入实际请求总量。成本/合格任务=月度所有成本÷(N×r)。不应把取消、失败或人工返工隐藏。比较本地时，设备本来就有并不代表零机会成本；用预计使用寿命估算折旧，并记录功耗及维护工时。对于低频任务先试已有工具；高频重复任务才值得算API集成成本。对隐私有硬约束时，先排除不合规方案，再比较价格。

本计算器仅在浏览器根据输入计算，不请求外部API；未包含质量差异、费用阶梯及税费。作者账单及模型真实费用待补充。
