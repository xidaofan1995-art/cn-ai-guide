# 文章越来越多，如何让网站越做越轻松？

**B06 · AI工具与工作流 · 初稿 / 方案研究 · 2026-11-27**

> 本页为公开初稿，可持续修订；作者未补充的个人观点留空，构造案例、AI建议与实际测试分开。动态信息在后续更新前复核。

![Notion、GitHub与独立站的三层内容架构](/images/topics-b06.svg)

## 30秒概览

1. 内容编辑、正式版本和网页展示分开，不必每篇重新建一张 HTML。
2. Notion 管创作，GitHub 管可回滚的发布快照，独立站管读者体验。
3. 自动化不是起步必选项，先把审核、版本、回写规则跑通。

当一个网站只有几篇文章，直接写网页很方便。几十篇之后，真正的问题会变成：哪份是最新正文？改一次导航要不要改几十个页面？其他 AI 修改了什么？谁确认过公开内容？

## 5分钟理解与决策

| 方案 | 编辑协作 | 页面自由度 | 维护成本与限制 | 适用 |
| --- | --- | --- | --- | --- |
| 直接写网页或 Markdown | 技术人员方便 | 高 | 非技术编辑审稿需另建流程 | 少量内容、单人维护 |
| Notion Site / 直接渲染 | 方便 | 取决于渲染方式 | 权限、缓存、样式及交互能力需检查 | 简单知识库 |
| Notion → GitHub → 静态站 | 编辑与正式版本分离 | 高 | 初期需转换、审批、构建与回写 | 长期协作型知识平台 |

这不是工具排名。对于只分享笔记的人，Notion 本身足够；对需要统一视觉、独立交互和长期维护的网站，第三种方式更有意义。

### 内容与展示分离

把网站当作图书馆：书的正文不同，书架、索引、排版和阅读设施可以统一。普通文章用 Markdown；需要筛选、计算或实验的页面再调用经过审核的 Vue 组件。专题地图、对比决策、工作流、交互实验、真实复盘可共享样式，但不必强制同一布局。

**已核事实（2026-11-27）：** 本站仓库的 package.json 使用 VitePress 1.x，构建脚本为 `npm run docs:build`，配置中已有本地搜索与现有导航。VitePress 将 Markdown 与主题生成静态页面，并支持 Vue 扩展。当前站点不需要为了这套内容架构迁移框架。[VitePress 官方说明](https://vitepress.dev/guide/what-is-vitepress)；[站点源码](https://github.com/xidaofan1995-art/cn-ai-guide)。

### 策划栏目与网站导航怎样共存

| 策划栏目 | 现有导航的关联入口 |
| --- | --- |
| AI全景认知 | AI 基础、模型与比较 |
| AI工具与工作流 | 工具实测、提示词库 |
| AI×智能硬件 | 知识专题、实战案例 |
| AI×外贸出海 | 工具实测、制造出海案例 |
| 个人实践与复盘 | 实战案例、知识专题 |

这是兼容性建议，不代表原导航必须迁移。保留既有文章地址，专题索引关联已上线文章，避免重复内容。

## 深度探索：让发布具有可审计的版本

| 环节 | 输入/产物 | 验收 |
| --- | --- | --- |
| 编辑 | 大纲、作者原始观点、可公开正文 | 原始输入与正文分离 |
| 批准 | 版本、内容快照、公开资源清单 | 明确授权，不混入草稿和评论 |
| 转换 | Markdown、稳定 slug、图片及组件 | 不执行原文中的任意代码 |
| 构建 | Git 提交、静态网页 | 检查断链、图表、移动端及组件 |
| 部署 | 发布版本、URL | 成功后回写；失败保留旧版 |
| 维护 | 回访记录、变更原因 | 动态数据、失效链接与交互重测 |

GitHub Pages 支持通过 Actions 构建并部署静态内容，[官方工作流说明](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)（2026-11-27）。本站已有 GitHub Pages 构建工作流；Notion 自动同步、内容快照校验及自动回写仍是拟建设能力，不能当成已经完成。

**AI建议：** 先用手动同步 Markdown 建立最小闭环，稳定后再开发 API 导出。仅同步公开正文，禁止导出内部意见、个人资料、密钥；使用私有编辑连接，公开链接不等于授权写入。建议每月抽查动态内容和失效链接，重大功能或政策变化时提前复核，长期知识按需回访。已发布页面应可从最近安全版本恢复。

作者观点：待补充。尚无自动化稳定性或节省工时的实测。
