## 30秒概览
供应链不是单一工厂名单。先看当前阶段要交付什么，再找对应供应商。样品能亮机不等于量产可控，低报价也不等于最终成本低。

## 5分钟理解与决策
| 角色 | 典型交付 | 验收重点 |
| --- | --- | --- |
| 创客服务/原型 | 开发板、手板、原型 | 概念及接口 |
| ID/ME/EE | 外观、结构、电路、固件接口 | 图纸、版本、设计权属 |
| PCB/PCBA | 裸板或贴装板 | Gerber、BOM、检测记录 |
| 模具/包材 | 模具、结构件、包装 | 公差、寿命、承认样品 |
| 方案商/ODM | 参考设计或整机开发生产 | 设计资料、IP、MOQ、测试 |
| OEM/工厂 | 按约定规格制造 | 品质一致性、交期与追溯 |
| 实验室/物流/渠道 | 测试、运输、销售与服务 | 目标市场、文件及交付能力 |

ODM与OEM的实际合同范围可能重叠。应明确设计所有权、软件更新、模具归属、变更流程、责任边界，不能只看名称。

## 深度探索：筛选供应商
在原型期优先能小批迭代的工程服务；设计冻结后再比较试产、检具、工艺能力与质量；量产前验收材料、追溯、关键部件供货、认证和包装。MOQ、模具和工程费需询价，不给无证据的固定价格。建立询价单：产品功能、目标市场、阶段、预计量、接口、关键公差、测试要求、资料归属、变更及售后。AI可整理供应商公开信息，实地核验、样品承认和工艺审核必须由人负责。
