## 30秒概览
水墨屏不是需求，用户需要的是易读、低打扰、可信的环境信息。先验证场景再定显示技术；没有真实证据时先观察，不宣称市场机会已经成立。

## 5分钟理解与决策
以美国和德国作为候选市场，先分别记录电商、零售及专业渠道样本的采集日期、售价、评价、功能、地区和销售条件。评价需保留原文和抽样范围，不能用AI虚构痛点排名。
| 方案 | 适合 | 风险与验证 |
| --- | --- | --- |
| 水墨屏 | 常显、低频更新、明亮环境阅读 | 刷新、残影、低温、暗处可读 |
| LCD | 动态彩色显示、实时更新 | 背光与功耗、视角 |
| 手机App | 丰富趋势和远程提醒 | 无屏即时阅读、连接与账号 |

【已核事实】[E Ink技术说明](https://www.eink.com/tech/detail/Benefits)介绍双稳态特性（2026-11-27查阅）；显示保持与整机耗电不是同一个概念，传感器、通信和刷新都要计算。
| MRD输入 | 证据与下一步 |
| --- | --- |
| 用户是谁、在哪里看 | 真实访谈、评论、家庭场景 |
| 检测哪些参数 | 传感器能力、标定与误差 |
| 为什么需要显示 | 与LCD、App、无屏方案对照 |
| 电池与安装 | 功耗测试、安装方式、换电池 |
| 可生产与销售 | BOM、模具、认证、售后 |

## 深度探索：把假设变成验证计划
以“放在卧室桌面，每天无需打开手机也能看温湿度”为假设（非作者实测），比较可读性、响应速度、准确性、成本和续航。用代表性竞品建立同口径规格表；测试环境参数应有参考仪器，电池寿命由实测耗电及工况推算并复核。只有需求证据、成本和供应链、目标市场合规同时可接受，才考虑进入。未获得完整评论、报价和实验记录，当前建议是观察；不提供虚构销量或市场规模。
